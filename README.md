# Rabbit Hole

一个持续生长的视觉实验合集，收录由代码生成的界面、交互、动态系统，以及那些值得保留下来的美丽意外。

## Experiments

- [春池 · Spring Pond](./spring-pond/) — 上传图片，在可交互的水面中观察雨滴、波纹与折射。

## Local preview

这是一个无构建依赖的静态站点。在仓库根目录启动任意静态文件服务器即可预览，例如：

```sh
python3 -m http.server 4173
```

## Publishing

推送到 `main` 后，GitHub Actions 会自动将整个仓库发布到 GitHub Pages。
